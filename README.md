# جِم فلو · GymFlow

موقع لتنظيم تمارينك في النادي: جداول، تسجيل أوزان، أرقام قياسية، مؤقت راحة، قياسات الجسم، ورسوم بيانية للتقدّم.
لا يحتاج أي تثبيت أو بناء (no build step): كل الملفات جاهزة، ترفعها كما هي ويشتغل.

---

## المميزات

| القسم | ماذا فيه |
|---|---|
| الرئيسية | بار يُحمَّل بقرص مع كل حصة هذا الأسبوع، تمرين اليوم من جدولك، إحصائيات، أحدث الأرقام القياسية، وزن الجسم |
| الجداول | إنشاء/تعديل/حذف/نسخ الجداول، ٥ قوالب جاهزة (دفع/سحب/أرجل، علوي/سفلي، جسم كامل، عضلة لكل يوم، وقالب L)، ربط كل يوم بيوم في الأسبوع |
| التمرين | تسجيل الوزن × التكرار لكل مجموعة، أرقام المرة السابقة تظهر تلقائيًا، مجموعات إحماء، مؤقت راحة تلقائي مع صوت واهتزاز، إضافة/استبدال/ترتيب التمارين، ملاحظات، الشاشة لا تنطفئ أثناء التمرين، والتمرين الجاري محفوظ لو قفلت الصفحة |
| السجل | تقويم شهري، تفاصيل كل تمرين، تعديل/حذف/تكرار، حفظ أي حصة كيوم في جدول |
| التقدّم | رسم 1RM التقديري/أثقل وزن/الحجم لكل تمرين، الحجم والحصص الأسبوعية، المجموعات لكل عضلة |
| الجسم | وزن الجسم برسم بياني، مؤشر كتلة الجسم، قياسات (صدر، خصر، ذراع…) |
| التمارين | مكتبة ٩٩ تمرين بالعربي والإنجليزي مع قسم الأرجل، بحث وفلترة، تمارين مخصصة، وصورة متحركة وشرح لكل تمرين (زر الصورة بجانب اسم التمرين) |
| الأدوات | حاسبة 1RM، حاسبة الأقراص، مجموعات الإحماء، مؤقت راحة، تحويل كجم/رطل |
| المتابعة والنجوم | للمالك: قائمة المسجّلين ومتابعة تمارينهم ومجموع ما رفعوه، وإعطاء نجوم (أو خصمها) مع ملاحظة. يرى المسجّل نجومه في الرئيسية |
| الإعدادات | عربي/English، داكن/فاتح/تلقائي، ثلاث ثيمات (كلاسيكي، حديد، وردي بفيونكة)، كجم/رطل، هدف الأسبوع، بداية الأسبوع، نسخة احتياطية JSON، تصدير CSV (يفتح في Excel)، استيراد |

يعمل على الجوال والكمبيوتر، ويمكن تثبيته على الشاشة الرئيسية كتطبيق (PWA).

## وضعان للتشغيل

1. **الوضع المحلي (يعمل فورًا):** إذا تركت `js/config.js` فارغًا، البيانات تُحفظ في متصفح الجهاز فقط. مناسب للتجربة.
2. **وضع الحسابات (المطلوب):** بعد ربط Firebase (مجاني) يصير فيه تسجيل دخول بالبريد أو Google، وكل مستخدم بياناته في حسابه وتظهر على أي جهاز.

> ⚠️ لا تفتح `index.html` بالضغط المزدوج: المتصفحات تمنع ملفات JavaScript الحديثة من `file://`. للتجربة على جهازك افتح موجّه الأوامر داخل المجلد واكتب:
> `python -m http.server 8000` ثم افتح `http://localhost:8000`
> (أو استخدم إضافة Live Server في VS Code).

## الخطوة ١: إنشاء Firebase (مرة واحدة، حوالي ١٠ دقائق)

1. ادخل <https://console.firebase.google.com> وسجّل بحساب Google.
2. **Create a project** ← اكتب اسمًا (مثلاً `gymflow`) ← تقدر تعطّل Google Analytics ← Create.
3. **تفعيل تسجيل الدخول:** من القائمة **Build → Authentication → Get started**:
   - **Email/Password** ← Enable ← Save.
   - **Google** ← Enable ← اختر بريد الدعم ← Save.
4. **إنشاء قاعدة البيانات:** **Build → Firestore Database → Create database**:
   - اختر **Production mode** (أو Start in production mode).
   - اختر موقعًا قريبًا (أي منطقة متاحة)، ثم Create.
5. **قواعد الحماية (أهم خطوة):** في Firestore افتح تبويب **Rules**، احذف الموجود، والصق محتوى ملف `firestore.rules` من هذا المجلد كاملًا، ثم **Publish**.
   هذه القواعد تضمن أن كل مستخدم يقرأ ويكتب بياناته فقط.
6. **ربط الموقع:** ⚙️ **Project settings → General** ← في الأسفل **Your apps** ← اضغط أيقونة الويب `</>` ← اكتب اسمًا ← **Register app** (لا تفعّل Hosting هنا) ← ستظهر لك قيم `firebaseConfig`.
7. افتح `js/config.js` بأي محرر نصوص (Notepad يكفي) والصق القيم بين علامات التنصيص:

```js
export const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "gymflow-xxxx.firebaseapp.com",
  projectId: "gymflow-xxxx",
  storageBucket: "gymflow-xxxx.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef"
};
```

> هذه المفاتيح **ليست سرّية** ويُسمح أن تكون في مستودع عام؛ Firebase مصمم لذلك، والحماية الفعلية من قواعد الخطوة ٥.

## الخطوة ٢: الرفع على GitHub Pages (مجاني)

1. أنشئ حسابًا في <https://github.com> ثم **New repository** ← اسم مثل `gym` ← اختر **Public** ← Create.
2. في صفحة المستودع: **Add file → Upload files** ← اسحب **محتويات** مجلد GymFlow (الملفات والمجلدات `css`, `js`, `assets`, `index.html`…) وليس المجلد نفسه ← **Commit changes**.
   تأكد أن `index.html` يظهر في الصفحة الرئيسية للمستودع مباشرة.
3. **Settings → Pages** ← تحت *Build and deployment* اختر **Deploy from a branch** ← Branch: `main` و `/ (root)` ← Save.
4. بعد دقيقة أو اثنتين يصير رابطك: `https://اسم-المستخدم.github.io/gym/`
5. **ارجع لـ Firebase:** **Authentication → Settings → Authorized domains → Add domain** ← اكتب `اسم-المستخدم.github.io` (بدون https وبدون اسم المستودع). بدون هذه الخطوة لن يعمل الدخول بـ Google.

خلاص! افتح الرابط وسجّل حساب. 🎉

### بدائل مجانية للاستضافة (تعمل بنفس الملفات)
- **Cloudflare Pages** أو **Netlify**: تقدر تسحب المجلد وتفلته في الموقع مباشرة (Drag & drop). أضف النطاق الناتج في Authorized domains.
- **Firebase Hosting**: يحتاج تثبيت Firebase CLI. النطاق يُضاف تلقائيًا.

## تحديث الموقع لاحقًا

1. ارفع الملفات المعدّلة فوق القديمة في GitHub.
2. غيّر رقم الإصدار في أول سطر من `sw.js` (مثلًا `gymflow-v1.0.1`) حتى يحصل كل الأجهزة على النسخة الجديدة مباشرة.

---

## هل بياناتي تنحذف؟

- **مع Firebase:** البيانات محفوظة في حسابك على Firestore ولا تنحذف بسبب قلة الاستخدام. الخطة المجانية (Spark) لا تطلب بطاقة ولا تولّد فاتورة؛ إذا تجاوزت الحد اليومي يتوقف الحفظ حتى اليوم التالي فقط. الحدود (حسب صفحة Firebase وقت الكتابة: حوالي ٥٠ ألف قراءة و٢٠ ألف كتابة يوميًا و١ جيجا تخزين) أكبر بكثير من احتياج شخص أو مجموعة أصدقاء.
- **الموقع يعمل بدون إنترنت** داخل النادي: التسجيل يُحفظ على الجهاز ويُرفع تلقائيًا عند عودة الاتصال.
- **احتياطًا:** صدّر نسخة احتياطية من **الإعدادات → نسخة احتياطية** كل فترة. تقدر تستوردها في أي وقت.
- **الوضع المحلي:** البيانات في المتصفح فقط، وتضيع لو مسحت بيانات المتصفح. صدّر نسخة احتياطية بانتظام.

## مشاكل شائعة

| المشكلة | الحل |
|---|---|
| صفحة بيضاء عند فتح الملف محليًا | لا تفتحه بالضغط المزدوج، استخدم `python -m http.server` |
| «هذا النطاق غير مضاف في Firebase» | أضف نطاق موقعك في Authentication → Settings → Authorized domains |
| «طريقة الدخول هذه غير مفعّلة» | فعّل Email/Password أو Google في Authentication → Sign-in method |
| «تعذّر تحميل بياناتك» / permission-denied | تأكد أنك نشرت محتوى `firestore.rules` في تبويب Rules |
| التعديلات لا تظهر بعد الرفع | غيّر رقم VERSION في `sw.js`، أو حدّث الصفحة مرتين |
| 404 في GitHub Pages | تأكد أن `index.html` في جذر المستودع وليس داخل مجلد فرعي |

### English (short)
Static site, no build step. Leave `js/config.js` empty for local mode, or create a free Firebase project (Email/Password + Google auth, Firestore in production mode), publish `firestore.rules`, paste your web config into `js/config.js`, upload the folder contents to a public GitHub repo, enable Pages (main / root), and add `<user>.github.io` to Firebase Authorized domains.
